# Эксперимент по генерации pandas кода для WikiTableQuestions

## Контекст
Мы использовали **Qwen Coder (next)** для генерации кода на pandas по задаче **WikiTableQuestions**. Модель получала на вход:
- сериализованную таблицу,
- названия колонок,
- вопрос.

Цель модели — сгенерировать код, который возвращает правильный ответ.

## Схема генераций (три этапа)

### 1. Первая генерация (прямая)
Модель генерирует код на основе исходных данных (таблица + вопрос).

### 2. Вторая генерация (коррекция синтаксиса)
- **Условие:** код из первой генерации упал с ошибкой.
- **Вход модели:** исходные данные + сгенерированный код + текст ошибки (4 попытки с повышением температуры на 0.23 начиная с 0.3).
- **Задача:** исправить **синтаксическую ошибку**.

### 3. Третья генерация (логическая коррекция)
- **Условие:** код из первой генерации был синтаксически верным, но давал неверный результат.
- **Вход модели:** исходные данные + сгенерированный код (из первого или второго этапа) (4 попытки с повышением температуры на 0.23 начиная с 0.3).
- **Задача:** исправить **логическую ошибку** (не меняя синтаксис).

## Интерпретация логики

```text
1. Сначала модель пытается решить всё сама (прогон 1).
   - Большая часть ответов неправильная или падает с ошибкой.

2. Если код упал с ошибкой → включается синтаксическая коррекция (прогон 2).
   - Она помогает исправить ~25% от упавших случаев.

3. Если код синтаксически верен, но ответ неверный → включается логическая коррекция (прогон 3).
   - Она улучшает результат примерно на ~15–25% от оставшихся ошибочных.

4. В итоге после трёх этапов доля правильных ответов достигает 62%.
